Workflow Overview

The workflow shows the four-phase process: Binary Feature Selection → Binary Classification & XAI → Multiclass Feature Re-selection → Multiclass Classification & Attack-Type XAI

  • Phase 1: Binary Feature Selection — Preprocess dataset, train initial LightGBM binary classifier (benign vs. malicious), generate SHAP importance rankings, and select top features for downstream modeling.
  • Phase 2: Binary Classification & XAI Analysis — Train multiple binary models (DecisionTree, RandomForest, XGBoost, DNN, MLP) on selected features. Generate dual XAI explanations (SHAP + LIME), perform multi-dimensional quality assessment (faithfulness, robustness, complexity), and produce LLM-powered global & individual interpretations for benign vs. malicious traffic patterns.
  • Phase 3: Multiclass Feature Re-selection — Filter malicious-only samples, train LightGBM multiclass classifier to distinguish attack types, re-rank features via SHAP, and select top attack-discriminative features.
  • Phase 4: Multiclass Classification & Attack-Type XAI — Train multiclass models on attack-specific features, generate class-wise XAI explanations (per-class SHAP, LIME), evaluate explanation quality, produce LLM-generated attack-type insights, and synthesize all results into an interactive dashboard.
